Public Hash List sources

The Public Hash List (PHL) merges SHA-256 digests from several independent sources into the availability-gating allowlist for Cross-Origin Storage. A digest that several sources vouch for is corroborated; a digest only one source knows about rests on that source alone. The diagram shows how the sources overlap, with circle and overlap areas approximately proportional to the number of digests.

Scroll or pinch to zoom, drag to pan, and click a circle to zoom to it. Small sources sit inside the large ones, so zoom in or use Locate to find them. Areas come from a numerical layout, so a few overlaps are drawn where the data has none; the tooltip always gives the exact count.
